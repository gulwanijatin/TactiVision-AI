# TactiVision AI

AI-powered football video analysis prototype for exploring player positions and tactical patterns.

## Project Overview

TactiVision AI analyses football footage using computer vision to detect people and display their estimated positions on a 2D football pitch.

## Current Features

- Upload a football video.
- Detect people using YOLO.
- Display annotated video frames.
- Estimate positions using bounding-box coordinates.
- Visualise detected positions on a 2D pitch.

## Technology Stack

- Python
- Streamlit
- OpenCV
- Ultralytics YOLO
- NumPy
- Matplotlib
